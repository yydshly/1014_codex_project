# 项目图片

保存本子项目的界面截图、结构示意图和其他研究配图。建议使用 `preview.png` 作为首页配图，其他文件使用 `01-home.png`、`02-workflow.png` 等有顺序的名称。

总索引中的 `preview` 相对于本项目根目录，例如 `assets/preview.png`；`preview_caption` 是图片的简短功能说明。真实图片存在后再登记，然后运行 `python scripts/project_catalog.py sync`。

在这里补充每张图片的含义、来源与使用条件：

| 文件 | 展示内容 | 来源 / 研究版本 |
| --- | --- | --- |

图片优先使用 PNG、JPG 或 WebP，控制尺寸以便 GitHub 阅读。SVG、GIF 也可用于示意图或短动画。
