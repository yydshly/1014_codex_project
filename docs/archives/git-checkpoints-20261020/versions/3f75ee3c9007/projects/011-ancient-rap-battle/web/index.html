      TRY THE IDEA / 原理示意

      为什么“把画面提前一点”会有用？

      假设生成画面里的嘴部动作，比原歌曲整体晚了 200 毫秒。保持歌曲不动，剪辑时从视频更靠后的位置取画面，就相当于让画面提前播放。

      试着补偿这 200 毫秒。这个例子只演示整体时差；模型改唱、嘴型画错或节奏逐渐漂移，不能靠一次平移解决。
