## 查找与恢复

- `manifest.json` 列出原路径、快照树、Git blob、SHA-256 和归档路径；同一路径的多个版本分别保存。
- `versions/` 保留原始字节，避免换行转换导致哈希改变。原 `.gitignore` 使用 `.gitignore.txt` 文件名，防止归档中的历史忽略规则生效。
- `snapshot-layouts.json` 保留三个快照的完整路径、模式及对象 ID 映射。它用于追查历史，不包含每个对象的原始内容，不能单独恢复完整快照。
- 需要恢复旧版本时，按清单找到文件，先核对 SHA-256，再复制到另一个研究目录比较；不要直接覆盖当前源码。
