# 数据来源与证据规则

当前实现见 [web/README.md](web/README.md)。已支持本地文本/JSON 导入、原文哈希与位置、人工事件分组、撤回级联删除。本轮真实模型试跑只使用 [原创合成样例](web/sample.json)，未将下列候选公开讨论伪装成已准入语料。发布时间、受访者同意与代表性须操作者独立核实，系统登记使用权说明并不代替实际授权。

## 首版来源

| 来源 | 对象 | 获取方式 | 用途/限制 |
| --- | --- | --- | --- |
| 用户有权使用的资料 | 访谈转写、客服反馈、去标识工作记录 | 文件或粘贴，登记授权范围 | 工作过程、现用工具与成本自述；避免用途超出许可 |
| 真人访谈 | 实际负责订单的微型烘焙经营者 | 操作者独立组织，取得同意后导入 | 动机、替代办法与选择；仍有招募和自述偏差 |
| 公开讨论 | 订单、生产汇总与分装求助 | 先登记链接，适用权限确认后才入库 | 发现线索；公开可见不等于可批量采集或商用 |
| 官方产品资料 | Bakesy、Bake That Batter | 小范围核查公开页，记录时间/哈希 | 功能与价格；缺失功能要另核实 |
| 可选技术反馈 | 相关工具公开 issue/讨论 | 适用条款内的官方 API | 故障和现有办法；开发者不等于经营者，非首轮必需 |

不以未获准的社媒爬虫作为启动前提。Reddit 的接入和用途按其当前规则确认；候选帖子仅解释问题来源，不能凭登记链接认定可投商业语料。拿不到适用许可时，使用有权处理的访谈与用户材料，不经镜像、登录态或其他工具绕过限制。

小红书、抖音、X、Instagram 首轮不接入。搜索摘要只能找链接，不能成为用户引文。GitHub API 访问也不自动赋予内容再分发或训练权利。依据见 [SOURCES.md](SOURCES.md)。

## 线索与正式语料

[source-register.json](data/source-register.json) 包含 4 条用户讨论、2 个产品页面，所有 corpus_eligible 当前为 false。本次没有保存原始正文、私人表格或个人资料。

入库顺序：确认使用范围 → 获取正文 → 去标识 → 记录时间和内容哈希 → 人工核查摘录 → 分配证据 ID。能打开链接只完成其中一步。

开发语料目标 20–30 个独立来源单元，至少保留 5 个反证/已解决案例；这些是采样目标，不是已完成数量。达不到就报告覆盖不足，不用转载补齐。

## 对象字段

| 对象 | 必要字段 |
| --- | --- |
| Source | ID、URL/本地引用、平台、发布日期（可未知）、访问时间、方式、权限、内容哈希、失效状态 |
| Evidence | ID、来源 ID、段落/偏移、必要引文、上下文、作者匿名键、来源簇、事实/自述/厂商说明类别 |
| Claim | ID、主张、支持/反证 ID、支持强度的文字理由、未知项、审核状态 |
| Persona | ID、人群原型、每项特征的依据、推断及理由、未知字段、适用范围、更新时间 |
| Run | ID、简报、组别、模型精确版本、语料/提示词哈希、调用、消耗、时间、输出、审核 |

原文存于被 Git 忽略的 data/private。引文保存定位和哈希；无法回查的主张降级或移除。原始内容最小化留存，授权凭据与正文分开。

## 去重与独立性

1. 规范 URL，剔除追踪参数，保留帖子/评论 ID。
2. 同一作者、事件、转帖、引用同一采访的文章合到 source_cluster_id。
3. 相似引文只触发人工检查，不能仅凭语义相似判断同一作者。
4. 不按相似用户名拼接跨站真实个人；身份资料不足则未知。
5. 整串评论、关联转帖和近重复内容按来源簇划分集合，不能跨开发/留出集合。

## 原型规则

首版是工作方式原型，如聊天收单、表格汇总、标准表单收单；不代表具体真人，不估算人口比例。

特征标为 observed、inferred、unknown；无依据的年龄、收入、性格、性别、市场占比保持未知。单次行为不自动成为群体特征。

模拟使用相同候选与问题，允许资料不足。输出进入 hypotheses，不能生成真实来源 ID 或成为事实依据。先实现证据流程，再决定是否保留模拟。

## 真人与留出设计

- 计划 6 名校准参与者，用来改提纲和流程。
- 另计划 12 名未参与校准的经营者做探索性留出评测；不能据此证明广泛市场效果。
- 留出者先提供基础访谈 F1，再独立提供 8 个未向系统公开的场景回答 F2。B/C/D 接收相同 F1；F2 只由独立评测器读取。
- F1 不包含 F2 答案或近义复述。发生泄漏则该参与者的评测作废并报告。
- 系统预测冻结前不把中间结论反馈给参与者，避免改变其回答。
- 问卷选择不等于实际付款；后续真实试用/收款另外记录。

## 隔离与撤回

联系人、同意记录、正文分别保存。外部报告只用匿名标识，不显示联系方式、地址或无关隐私。撤回资料会使相应证据、原型和报告失效，并触发复核。

研究服务的输入 allowlist 不含 evaluation/holdout。留出答案由独立进程/存储提供给评测器，不能只靠提示词禁止读取。
