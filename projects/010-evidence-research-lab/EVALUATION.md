# 验证协议：先证明增益，再保留复杂度

版本 design-v0.1。阈值是预先提出的产品取舍，全部未实测，也未完成统计功效分析。

**执行补充（2026-10-15）**：v0.1 已用真实本机模型完成一轮合成资料 B/C 流程试跑，见 [bc-smoke-result.json](evaluation/bc-smoke-result.json)。它不属于下面的正式开发/留出实验，没有真人盲评和效果胜率；`experiment.json` 保留 design_only。A、D 未实现。B/C 保证相同原文、请求模型和推理设置；不可变模型快照与美元成本无法从当前接入观察，正式实验前仍需解决。C 两次调用与 B 一次调用的消耗完整报告，不把额外推理预算的影响归因为纯证据格式。

## 三个问题

- H1：完整工具是否比直接联网调研产生更多可信、可行动发现，或节省人的时间？
- H2：底层资料相同时，结构化证据和反证流程是否优于直接读资料？
- H3：加入人设模拟是否进一步提高真人选择预测或有效发现？

H1 不能直接证明 H2/H3。群体文本相似度也不能代替真实成交验证。

## 四组设置

| 组 | 输入与能力 | 约束 | 解释 |
| --- | --- | --- | --- |
| A_live_web | 简报 + 同一 F1 + 同一模型 + 常规搜索和读取 | 不喂 C/D 整理结果；提示词认真优化 | 与 C/D 比较整体产品，公开资料差异单独解释 |
| B_same_corpus | 简报 + 全部冻结基础资料，直接分析 | 无联网、无整理标签/人设 | C/B 检验研究工程 |
| C_evidence | 与 B 相同资料 + 抽取/去重/反证/引文审核 | 无联网、无模拟 | D/C 检验模拟增益 |
| D_simulation | C + 最多 3–5 原型、4 个问题 | 无联网；模拟不产生真实证据 | 无增益则关闭 |

独立策展步骤预先冻结 B/C/D 基础语料，包含同样的获准公开资料和 F1 访谈。全部基础资料必须装入预定预算；B 不能得到人为劣化的截断版。C/D 中间整理和原型是其处理步骤，消耗计入总量。

H1 改善而 H2 无改善，优先考虑数据服务；H2 改善而 H3 无改善，保留证据工具、取消模拟。

## 公平预算与运行

- 同一供应方、精确模型版本/快照、推理设置、温度与工具实现；不用浮动 latest 别名混跑。
- 统一报告契约：最多 8 条发现，3,000 输出 token；事实/推断/模拟分区一致。
- 每次所有调用合计最多 30,000 模型 token、12 次模型调用。整理、人设、重试都计算；可观测的推理 token 单列并计入，不可观测则披露。
- 每次最多 0.50 美元，开发整轮最多 72 美元，含模型和搜索工具费用；这是自定约束，不是价格承诺。实际 token 预算在选定模型计价后反算，先触及哪项就中止。
- A 最多 8 次搜索、12 次页面读取；B/C/D 只读冻结资料。
- 资料装不下时，在随机化前按同一方案裁剪所有组，再冻结；不能看结果后偏向某组调整。
- 每题每组重复 3 次，独立会话、随机顺序、无跨组记忆。只对明确传输故障重试 1 次，并保留失败和费用。
- 网络失败、无资料、额度中止都计入失败率。不能删除坏结果。
- A 网页记录访问时间、可用摘录和哈希，48 小时内跑完同批比较；来源明显变化时分批解释。
- 缓存、首跑与复用成本分开报告，不能只给某组优惠计价。
- 人工找资料、设置、复核和改错时间另计。

正式运行前锁定模型、计价、权限、题目、语料、提示词、评审与哈希。本次没有密钥配置、付费调用或任何运行结果。

若单次上限不足以装入共同资料，或预检发现正常完成必然超支，则在随机运行前修改整轮预算并冻结新协议，不能只给某组放宽。不同组的人工和调用成本须完整列出。

## 开发集合与留出集合

[briefs.json](evaluation/briefs.json) 的 12 题是公开开发集合，覆盖问题、替代方案、迁移、范围与价格假设。开发轮上限 12 × 4 × 3 = 144 次，72 美元。

同一领域的 12 个问题不是独立市场样本；重复运行也不是新增真人。正式判断前由领域经营者另供未用于调参的题目，冻结相同规模评测集与全部规则，再执行。更改规则后作为新实验，不能回写旧协议。

正式留出轮按 12 名不同经营者建立 12 个研究案例，每人一个自己的决策简报；各组得到相同的该参与者 F1 和 8 道 F2 题目，但看不到 F2 答案。预测包含在该次报告中，不另增加隐藏调用或费用。A 也输出预测以保持输出任务一致，模拟增益主要看 D/C。正式轮另计最多 144 次、72 美元；开发与正式两轮设计上限合计 288 次、144 美元，均未执行。

## 指标

| 指标 | 计算/判定 |
| --- | --- |
| 引用支持率 | 人工核实有资料支持的可核验事实主张 / 全部可核验事实主张 |
| 虚构引文数 | 输入里不存在或错误归因的直接引文数 |
| 有效发现数 | 有依据、非重复、关联当前决策、领域评审认为可行动的发现数 |
| 反证处理 | 正确识别已解决案例、免费替代、人群差异；不只寻找开发理由 |
| 人工时间 | 从接题到报告可用于决策的主动操作分钟数，含获取、审核、改错 |
| 成本/失败率 | 全部工具/模型费用、人工成本与未完成比例 |
| 真人预测 | B/C/D 对同样 F2 固定题预测；报告宏平均 F1、覆盖率和混淆矩阵 |

强发现至少两条独立来源。正确标注的具体单来源自述也可计入有效发现，由评审判定其决策价值。模拟假设不计入已确认发现，换措辞不算新发现。

F2 事先固定 8 个场景题及候选，包含“不改变/都不选”。允许弃答，但共同比较覆盖率至少 80%，不能只挑容易题。12 人的重复答案有关联，区间按参与者重采样，不能把 96 道回答当独立真人。

题目起点见 [场景题模板](evaluation/holdout-questions.template.json)。各题先分别计算宏 F1，再对题目平均；类别计法在正式轮冻结，各组一致，并报告准确率、每类人数和缺类情况。缺类或样本过少的题不单凭 F1 下结论。模板不是已收集的回答，正式采样前必须检查是否与 F1 重复。

## 盲评

1. 冻结报告，评测器分配随机 report_blind_id，隐藏组别和顺序。
2. 统一展示字段，仍保留事实/推断/模拟区别；评审可能从内容猜方法，披露盲法局限。
3. 两名独立评审核查全部事实与发现，至少一名了解实际订单工作流。
4. 先评分再揭组；第三人处理分歧。模型辅助检查不代替最终人工判断。
5. 同义发现合并；同题三个重复先聚合，再比较组别。记录失败、分歧和最差案例。

## 继续与停止

| 阶段 | 预设探索性门槛 | 动作 |
| --- | --- | --- |
| 基本可信 | 引用支持率 ≥95%；虚构直接引文 0；无留出泄漏 | 不满足先修复，不扩范围 |
| C 的增益 | 相对 B，问题级有效发现中位数至少 +20% 且至少多 1 条；或有效发现不减、人工时间至少少 25% | 保留结构化证据流程 |
| D 的增益 | 相对 C，在相同覆盖率下真人宏 F1 至少 +0.10，引用质量/有效发现不下降，成本增加 ≤30% | 保留模拟，否则默认关闭 |
| 整体价值 | C 或 D 相对 A 同样达到质量/时间门槛，失败率不更差 | 才进入收费试点 |
| 付费线索 | 5 名目标产品使用者中至少 2 名按事前公开的试点价格付款、完成交付且未退款 | 继续线索，不推断市场规模 |

基线发现数为 0 时只报告绝对差，不夸大百分比。探索轮达标仍需第二批新问题与真人验证。没有足够样本时报告不确定，不以小样本显著性包装确定结论。
