# 图片来源与生成说明

| 文件 | 内容 | 来源与用途 |
| --- | --- | --- |
| `understanding-overview.png` | Fotor Agent 的核心能力、平台价值、对我们的价值、引发的思考与多模态 Agent 探索。 | 2026-10-19，我们使用内置 imagegen 生成的原创理解图；用于本项目简介与根 README 的代表配图。 |
| `image-prompt.txt` | 完整生成提示词。 | 本次自行撰写，保留图中文字、版式要求与证据边界，便于后续修订。 |
| `image-metadata.json` | 生成工具、图片尺寸、文件散列和来源依据。 | 图片生成及视觉核对后登记。 |

图像不是 Fotor 官网截图、生成案例、内部架构图或我们已经实现的系统。它将官方能力说明与本次讨论中的价值判断组织成引导图，不证明任何性能或费用优势。

内容依据为 [Fotor Agent](https://www.fotor.com/agent/) 与[官方动态图形说明](https://www.fotor.com/ai-video-generator/motion-graphics/)，详细边界见[简要依据](../RESEARCH.md)。没有搬运官方图片、Logo 或代码；不对 Fotor 商标或其产品内容主张权利。

生成方式为内置 imagegen，未使用 CLI 或自建模型 API。项目内保留所选最终原图及提示词，根索引与项目简介引用同一个 PNG 文件。
