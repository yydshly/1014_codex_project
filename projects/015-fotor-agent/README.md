# 015 · Fotor Agent：视觉创作平台的能力、价值与我们的取舍

Fotor 将图片与视频模型、Agent 编排和代码动画整合成视觉创作平台，帮助用户把创意与素材推进到可编辑、可导出的图片、设计图和视频。它的产品价值在降低制作与修改门槛；对会用 Agent 和代码的我们，主要参考工作流与编辑体验，是否采用取决于省时和成品成本。本轮整理理解并归档，未做生成效果或成本实测。

## 核心能力是什么

- **图片与设计**：图片生成、修图、海报、商品视觉等。
- **视频制作**：脚本与分镜、场景生成、配音、字幕、合成与导出。
- **对话编辑**：用自然语言提出需求和修改，通过编辑器继续调整。
- **代码动画**：官方介绍的 code-to-video 主要面向文字、图形、Logo、图表等动态图形；图片和视频生成模型也参与素材制作。

我们的概括是：**创意与素材 → Agent 编排 → 模型生成与代码制作 → 编辑、合成、导出**。这是基于公开说明形成的理解图，不是经源码验证的内部架构。相关功能依据见[官方 Agent](https://www.fotor.com/agent/)及[动态图形说明](https://www.fotor.com/ai-video-generator/motion-graphics/)。

## 价值是什么，对我们有什么价值

| 角度 | 我们的判断 |
| --- | --- |
| 对一般用户 | 把多种工具和制作步骤组织成可操作的产品，降低学习、素材拼装和修改的门槛。 |
| 对会用 Agent 与代码的我们 | 具备自建常用流程的条件；平台可作为编排、编辑体验和交付方式的参考，是否使用取决于实际省时程度。 |
| 自建时需要承担什么 | 模型调用之外，还需组织排版、时间线、音画同步、版本保存和修改；这些都计入交付成本。 |
| 如何判断是否值得采用 | 在相同任务和质量要求下，比较满意成品所需时间、费用、重试与人工修改次数。 |

**模型提供生成能力，平台通过流程和交互降低使用成本。** “调用模型”不能直接推导“没有产品价值”；“会写代码”也不能保证自建更省事。对我们，生成能力本身的增量较小，制作、修改与交付效率更值得比较。

## 引发的思考与可扩展探索

这次讨论引出的重点是：模型本身贡献了什么，Agent 与产品流程又增加了什么；前期积累的制作经验能否变成可复用工具，并持续减少返工。

可继续探索 **多模态 Agent 的工作流研究**：任务规划、工具调用、结构化项目状态、局部修改、质量评估，以及流程复用。未来若有具体制作需求，可在相同素材、模型和验收标准下，对比直接调用与 Agent 编排。此处仅保留研究方向，不代表已启动开发或证明流程增益。
