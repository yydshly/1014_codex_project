## 本地运行

需要 Node.js `^20.19.0` 或 `>=22.12.0`，以及支持 WebGL 2 的现代浏览器。已在 Node.js 22.15.0、npm 10.9.2 下验证。

在本项目 web 目录运行：

~~~powershell
cd F:\codex_project\1014_codex_project\projects\002-rainy-ghost\web
npm ci
npm run dev
~~~

浏览器打开 <http://127.0.0.1:4174/1014_codex_project/002-rainy-ghost/>。

也可以在 web 中运行 `./start.ps1`，脚本会在缺少依赖时安装，并启动开发预览。端口固定为 4174，避免与项目 001 的 4173 冲突；端口占用时直接提示。

## 可以做什么

| 操作 | 效果 |
| --- | --- |
| 拖动空白背景 | 环绕场景旋转视角，松手后平滑停下 |
| 滚轮 / 双指缩放 | 拉近或拉远；点击重置或按 R 回到初始视角 |
| 拖动幽灵身体 | 带着幽灵和提灯移动，身体带有惯性与倾斜 |
| 拖动下半部衣角 | 局部布料被拉起，松开后以阻尼弹簧回弹 |
| 轻点幽灵身体 / 点击“轻轻叫它一声” | 小幽灵挥手、开心回应 |
| 轻点提灯 / L | 调暗或重新点亮提灯 |
| 轻点水面 | 产生逐渐扩散、衰减的涟漪；拖动时旋转镜头 |
| 轻雨 / 夜雨 / 大雨 | 调整雨丝数量、水面雨纹与雨声音量 |
| 雨落在斗篷上 | 命中处出现局部湿斑和小水珠，湿斑晕开并向下流淌；大雨时偶尔眯眼 |
| 衣摆滴水 | 汇集的水分从当前衣摆位置滴落，在落水处留下小涟漪 |
| 声音 | 分别开启小幽灵的声音和雨声，调整音量或试听；默认静音 |
| 轻抚头顶 / 摸摸头 / H | 轻抚时先害羞、脸红，再顺着手轻轻歪头蹭一下；持续轻抚后安心眯眼，身体仍可拖动 |
| 暂停 / 继续 | 冻结雨、湿斑与水滴；静止时停止重复绘制，仍可拖动幽灵与操作镜头 |
| 方向键、空格、R | 画布聚焦后，分别移动、暂停、重置 |
| 右上角 ? | 展开操作说明；Escape 关闭 |
| 陪你专注一会儿 | 写下任务并计时；可暂停、继续或提前结束，完成后点亮远处一盏灯 |

鼠标和单指操作共用 Pointer Events。尊重系统的“减少动态效果”偏好，首次进入时自动暂停，用户可点击“继续”。

背景是实时 3D 水面、灯光和雨粒子。镜头由 OrbitControls 控制，角色拖拽会临时接管手势，避免同时旋转镜头。系统动画暂停时仍可转动视角；镜头角度与缩放距离有限制，避免钻入水下。

背景移动超过 7 px 才开始旋转，与轻点水面的判断共用同一阈值。手机竖屏会根据标题与控制栏之间的可用区域调整角色构图；矮屏标题改为紧凑排布，主要控制按钮的触摸高度至少 44 px。

画质默认自动调整。手机从均衡档开始，以约 60 帧为渲染目标；持续掉帧时降低渲染分辨率、倒影刷新、雨丝数量与细小雨纹，持续流畅后再缓慢恢复。各档都保留提灯暖光、倒影、雨丝、局部湿斑与衣摆滴水，白布材质参数共用同一套。斗篷使用较柔和的布料高光，湿斑与月光会让局部呈蓝灰色。

## 夜航 · 陪你专注一会儿

专注现在作为可选功能，放在右上角“听雨小记”的底部。写下一件小事，选 5、15、25 分钟，或自定义 1–180 分钟；留空任务时默认“陪自己专注一会儿”。开始后入口显示剩余时间，收起面板即可继续和小幽灵互动。

专注计时独立于雨夜动画。收起面板、暂停雨景、切到后台或刷新都不会打断正在运行的计时；主动点“暂停计时”才会暂停，恢复时不把休息时间计入陪伴。关闭页面后，运行中的任务仍按截止时间结算，再次进入时恢复或补记完成；浏览器关闭期间不会发送通知。

时间到后保存一条完成记录，并在 3D 水面远处新增一盏暖灯和真实倒影；再次进入会恢复灯火。点“先到这里，保存”会留下实际陪伴时长与“中途停下”记录，不额外点灯。场景重置只重置雨夜，不清空任务、记录或完成灯数。

累计时间、灯数与完整记录保存在当前站点的浏览器 localStorage，没有账号或云同步。清除网站数据会删除记录，更换浏览器或设备不会同步；保存不可用时面板会明确提示仅在当前页面保留。列表每次显示 20 条，可继续展开；完整记录保留在本地，3D 场景最多展示最近 32 盏奖励灯，控制持续使用时的渲染开销。原有白布材质、降雨反应、滴水、相机、拖动、雨声和自动画质保持原有逻辑。

## 雨夜小伙伴：什么也不做，也可以一起待着

主界面以小幽灵和雨景为主，不需要先填任务。鼠标靠近角色并停留片刻，它会慢慢看向你、轻轻抬灯；点击角色或“轻轻叫它一声”，会得到一声短短的回应。手机仍可点击打招呼，不模拟鼠标悬停。

几次招呼后，小幽灵会用较熟悉的点头、轻眨眼和抬灯回应。回来时也会给一个小招呼；这些是本地记忆和有限动作规则，没有语音识别或对话模型。自动文字回应留有间隔，片刻后消失；“听雨小记”里的“安静陪伴”会让靠近和回来时只保留动作，手动招呼仍会回应。

听雨时间自然保存，只计算页面可见时的相处；离开页面不继续累计。小记显示本次、累计时间及最近一起听雨的日子，不设目标或连续签到。偏好、招呼记忆和累计时长在同一浏览器刷新后保留；近 30 天按日存储，界面显示最近 7 天，历史总时长另行保留。页面恢复时限制单次长间隔，避免设备休眠后把整夜计入相处。

新增动作共用雨夜模拟时钟，暂停或隐藏页面时冻结；小记低频保存不会唤醒暂停的画布。原有镜头、角色拖动、衣摆拉扯、湿布、滴水、光照材质和自动画质继续保留。场景重置不清空相处记忆或已有专注记录。

## 小幽灵的声音

底部“声音”入口可以打开它自己的小叫声：圆润的低中频、轻轻的气息和很短的空间回响。开心时两次有弹性的上扬，害羞时两声小小的、带停顿的轻叫，安心时低低地舒展开来。招呼始终开心回应，摸头时用更短、更轻的害羞叫声，靠近与重新点灯还有简短的同族变化。声音与动作一起发生，不使用人声、语音合成或说话音节。

面板提供“开心 / 害羞 / 安心”三种试听和独立的回应、雨声音量。开启后，摸头、主动叫它、靠近或回来时才会有短短的回应；不会循环鸣叫。安静陪伴中只保留主动摸头、招呼和试听的声音。暂停或切到后台时会渐静，并收掉正在播放的尾音，恢复后不会补播旧声音。

每次进入页面都先静音，需要用户主动开启；音量设置保存在当前浏览器，原有相处记录、任务和灯火不变。音色在本地程序合成，没有外部音频素材、网络语音服务或新增依赖。

鼠标不必按键，在头顶、额头上半部轻轻来回滑动就能抚摸；手机用单指按在头顶，慢慢滑过也可以。它先害羞地缩一下、脸红，再顺着手的位置与滑动方向轻轻歪头、往前蹭一点，换方向时有柔和的迟缓。持续来回轻抚约 3–4 秒后会慢慢安心眯眼。停手后，它会轻轻睁眼，看一下鼠标离开的方向；手机抬指时沿最后轻抚的方向目送。稍停片刻后，用两三秒慢慢恢复待机，不另发声。静止按住或微小抖动不会累计安心状态。

鼠标停住、没有离开头顶时，也会在短暂等待后轻轻看向最后的位置，再自然回落；目送不会一直跟着鼠标。重新轻抚、打招呼或拖动身体会接回当前操作。取消触摸、多指、暂停和切到后台不会新触发目送。

头部专门用于轻抚，拖身体仍会移动角色，拖衣角仍会拉扯布料。轻点头顶、文字“摸摸头”和画布 H 键保留原来的短暂缩身、脸红与轻叫。脸红贴着布料，连续轻抚时仅保留一点淡粉；月光、提灯和白布材质沿用原有设置。

头顶有柔和手形光标与轻抚提示，身体是抓取手势，拖动时收紧；衣角是拉扯提示，提灯是可点击手势。轻抚根据头部的屏幕尺寸识别，快速掠过、微小抖动、离开头部、取消触摸和多指操作不会误触。连续轻抚只在开始时尝试轻叫，重新开始的轻抚叫声至少间隔 12 秒；变得安心时不另发声。按钮摸头与招呼仍共用至少 3 秒声音间隔。安静放着时，每隔约 18–34 秒偶尔缓缓眯眼，不伴随声音。暂停会冻结动作与脸红，并收掉尾音。

## 实现与边界

- 幽灵采用参数化网格、预设褶皱、连续波动、局部拉扯权重和弹簧回弹。材质使用 Three.js 的布料光泽；这是风格化变形近似，没有实现布料自碰撞或有限元求解。
- 雨滴轨迹在 CPU 与顶点着色器中同步，对当前变形网格做射线碰撞。命中后停止该滴继续下落，在接触位置产生短暂布料振动、接触圆纹和弹道小水珠。96 × 64 的 UV 湿润场记录局部湿斑，以固定步长近似扩散、下流和蒸发；程序织纹凹凸与局部颜色、粗糙度变化表现湿布。它是视觉近似，没有纤维吸水或真实湿布重量求解。
- 衣摆的 24 个汇水区域驱动最多 24 个可复用水滴。水滴从当前变形网格与角色变换后的衣摆发出，脱离后留在世界空间，以简化重力轨迹落水并触发较小、较快消散的涟漪。暂停冻结全部降雨反应；重置清空湿斑、汇水、水滴与涟漪。
- 水面采用 Three.js Reflector 渲染真实场景倒影，再由自定义 GLSL 扭曲倒影、计算高光并叠加雨纹和交互涟漪。水体是平面，水珠为粒子近似，没有体积流体求解。
- 雨丝由一个批量线段对象与顶点着色器驱动。提灯由几何体组合，暖色光源、微小摇摆和克制的 Bloom 营造氛围。
- 暂停静止时停止申请连续动画帧；拖动、灯光渐变和镜头阻尼结束后再次静止。仅操作镜头时不重算布料。自动画质使用实际绘制间隔与 CPU 提交耗时，每秒评估一次，带预热、升降档滞回与冷却；暂停、隐藏页面和尺寸变化会清空采样。已经过浏览器与模拟帧时间回归验证，手机实机的帧率、功耗和热稳定性尚未测量。
