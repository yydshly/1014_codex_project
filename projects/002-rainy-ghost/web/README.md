# 雨夜小幽灵 Web

纯浏览器 Three.js 应用，没有服务端、登录、数据库或运行时外部资源。

## 启动

需要 Node.js `^20.19.0` 或 `>=22.12.0`。

~~~powershell
npm ci
npm run dev
~~~

入口：<http://127.0.0.1:4174/1014_codex_project/002-rainy-ghost/>。本地快捷启动也可以使用 `./start.ps1`。

## 构建与验证

~~~powershell
npm run check
npm test
npm run build
npm run preview
~~~

保持预览运行，在另一个终端执行：

~~~powershell
node scripts/smoke.mjs
~~~

检查实际构建 HTML 中的脚本、样式和图标链接，确认能从编号子路径返回且不依赖 CDN。该检查不代替浏览器 shader 编译、视觉与交互验证；已完成的检查记录在上级 [RESEARCH.md](../RESEARCH.md)。

vite.config.js 使用 `/1014_codex_project/002-rainy-ghost/` 基础路径。产物在 dist，可复制至总发布目录 `_site/002-rainy-ghost/`。本次仅本地实现，尚未部署。

默认静音。浏览器不支持 WebGL 2 或图形上下文丢失时显示中文提示。页面隐藏或暂停静止时停止申请连续动画帧；交互和阻尼结束后自动静止。离开时释放图形与音频资源，并保留浏览器往返缓存恢复能力。

拖空白背景旋转视角，滚轮或双指缩放；点水面起涟漪，拖角色或衣角操作角色。角色拖动期间停用镜头控制；重置同时恢复角色和视角。镜头支持在暂停时操作，桌面与窄屏切换时恢复对应初始构图。

雨滴命中当前布料网格后触发局部变形和小水珠，并在该轮降落中隐藏已被布料截住的雨滴。斗篷逐渐变湿，画面右下方以自然语言提示湿润状态。命中、湿润积累和粒子运动共用动画时钟，暂停时冻结，重置后恢复干燥。碰撞和粒子有固定容量，不会随运行时间无限累积。

局部湿润使用 96 × 64 UV 数据纹理，以 20 Hz 固定步长近似扩散与下流；着色器只调节相应位置的颜色和粗糙度。24 个衣摆汇水区域、最多 64 条流淌轨迹和 24 个水滴槽均有上限。水滴在当前变形衣摆上取样，脱离后按世界空间弹道落水，回调场景生成小涟漪。没有新增外部素材或依赖。

画布的 data 属性提供只读验证状态：render-count、cloth-updates、idle、wet-coverage、wet-compiled、hem-drips、drips-landed 等。静止暂停后前两项应保持不变；转动镜头会更新 render-count，cloth-updates 应保持不变。

## 自动画质

默认启用，无需用户选择。按粗指针或较小视口使用手机预算，手机初始均衡档，桌面初始细腻档；窗口变化会重新计算像素预算，并保留已经学习到的较低档位。

| 手机档位 | 像素比上限 | 倒影尺寸 / 频率上限 | 活跃雨丝 | 布料 / 碰撞频率 | Bloom 内部尺寸比例 |
| --- | --- | --- | --- | --- | --- |
| 流畅 | 0.75 | 256 / 18 Hz | 650 | 24 / 24 Hz | 35% |
| 均衡 | 1.0 | 512 / 24 Hz | 1000 | 30 / 30 Hz | 50% |
| 细腻 | 1.35 | 512 / 30 Hz | 1400 | 45 / 30 Hz | 75% |

像素数还有每档总预算，并受设备实际像素比限制。桌面有更高预算，具体见 adaptive-quality.js。每档保留光晕、提灯暖光、倒影和交互涟漪；调整细小雨纹的采样数量，不改灯光强度、曝光、白布颜色或湿润状态。

手机绘制以约 60 fps 为目标，90/120/144 Hz 屏幕保留计时相位，避免整帧跳过造成错误的 45 fps 上限。实际呈现的帧间隔与每帧 CPU 提交耗时每秒汇总：持续低于 48 fps 约两秒时降一档，低于 30 fps 时更快响应；降档之间至少间隔四秒。连续达到 57 fps 且 CPU 有余量时才考虑升档，手机需约二十秒、桌面约十二秒，并满足冷却时间；恢复后很快再次掉帧则延长升档等待。

暂停、隐藏、恢复和尺寸变化会清空测量窗口，预热和资源调整期间不判断；没有额外定时器唤醒暂停场景。倒影平时按预算刷新，镜头发生变化或暂停中的操作需要新画面时立即更新。雨滴只分配一次，GPU draw range 与 CPU 碰撞检查使用相同的活跃前缀；布料弹簧按绘制帧更新，网格与法线按档位频率更新，拉扯衣角时保持及时反馈。

只读诊断属性包括 quality-mode、quality、quality-device、quality-changes、fps、frame-ms、work-ms、pixel-ratio、render-size、reflection-size、reflection-hz、reflection-updates、active-rain、bloom-scale、cloth-hz、collision-hz。fps 来自实际绘制间隔；work-ms 是 CPU 提交耗时，不等同于 GPU 执行耗时。性能采样以当前设备会话为准，不保存到外部服务。

## 专注与本地陪伴记录

专注入口位于“听雨小记”底部，默认收起，桌面面板位于左侧，收起后恢复原有标题；手机面板在视口内滚动，不改变相机构图。任务输入和控制都位于画布外，输入空格、方向键等不会触发场景快捷键。

FocusSession 使用实际日期时间、累计有效时长和运行起点，独立于场景动画时钟。每次开始、暂停、继续、提前结束和完成立即保存；隐藏页面和离开时保存检查点。运行中的标签页仅每秒更新数字，暂停或隐藏后停止该定时器，返回时按截止时间结算。完成时间与总时长不超过目标；结算后移除活动任务，重复刷新不会再次点灯。其他标签页通过 storage 事件读取更新，关键操作前也重新读取本地版本；这不是跨设备服务或数据库级并发事务。

localStorage 键为 `night-voyage.focus.v1`，版本 1 的结构为 `{ version, active, records }`。任务名称通过 textContent 输出，输入不解释为 HTML；存储被禁用、超出容量或旧数据不可读时切换到页面内保留并提示用户。无法解码的旧数据不会被空记录覆盖。

FocusLights 用三组 InstancedMesh 和一组 Points 表示最近最多 32 盏完成灯，共四次常规绘制调用，无新增动态点光源、物理步进或周期动画；反射仍由原水面渲染。完成或恢复时更新实例并使倒影失效，暂停雨景时仅按需绘制。灯光与主体材质没有改变，reset 不重置专注灯数。

面板提供只读 data-state、elapsed-ms、remaining-ms、records、lights、saved；画布提供 focus-lights 与 visible-focus-lights，便于从实际 UI 验证任务状态和真实场景奖励是否一致。

## 自然陪伴

本地记忆单独使用 `night-voyage.companion.v1`，不改专注记录。页面可见时每 5 秒保存一次有效停留；隐藏/离开立即结算并停止定时器，返回重新开始。单次最多补记 15 秒，避免设备休眠或长时间冻结后误计；这不是精确工时追踪。按日保留最近 30 个日期，累计总时长另存，界面列出最近 7 个有记录的日期。暂不合并多个同时打开标签页的相处时间。

3D 动作使用纯数值 CompanionMotion，由既有模拟时钟驱动，冻结时不会额外申请动画帧。根据鼠标射线距角色中心的距离设定注意力，停留约 0.7 秒触发一次注意到访；缓动视线、身体小角度旋转及手臂/提灯位置，继续使用既有材质、动态光源和网格。手机用点击回应。主动招呼有 4 秒记忆计数间隔；5 次招呼、3 次相隔较久的到访或累计约 15 分钟后使用熟悉动作，没有等级奖励。

自然文字回应至少间隔 40 秒，显示约 5.5 秒后收起；久坐时偶尔仅做轻动作。“安静陪伴”偏好保存到本地，抑制自动文字但保留主动打招呼。它是有限动作规则，不含麦克风、模型请求、消息通知或外部服务。只读面板 data 属性包括 total-ms、session-ms、familiar、greetings、quiet、saved、response；画布提供 companion-attention、companion-lift、companion-gesture，用于检查动作与暂停状态。

## 角色音色与声音控制

页面默认不创建 AudioContext。用户点击声音开关或试听后，NightAudio 才创建一个共享上下文；角色短音和雨声独立开关、独立音量。雨声仍使用原来的噪声循环与低通滤波，50% 雨声音量对应此前的雨势增益；角色默认 45%，总线用温和压缩控制叠加峰值。音量使用独立 `night-voyage.sound.v1` 本地键，只保存两个音量，不保存开启状态。

ghost-voice.js 用平滑音高曲线、正弦主音、少量整数倍泛音和微弱低八度合成圆润的小幽灵叫声。各段用柔和包络、带限气流、1.2–1.6 kHz 低通与很轻的短房间回响，减弱初版的玻璃金属感；直流滤波按采样率校准。没有人声、元音/音节拼接、TTS 或外部录音。happy 为两次上扬弹跳，shy 为更轻、更短、带犹豫停顿的两次轻叫，settled 为更低、更长的舒展声。旧事件 greet/welcome/return 映射 happy，nod 映射 shy；approach 和 light 使用同一音色的简短变化。每次在三种 ±9 音分的微变间轮换。角色横向位置仍轻微影响左右声像，不增加场景计算。

声音通过 CompanionUI 的有效回应事件联动，通常延后动作起点约 90 ms 发出。打招呼始终用 happy，不再因熟悉程度切成 shy；摸头使用 pet 的约 0.8 秒轻叫。面板提供开心、害羞、安心三种试听，分别联动招呼抬灯、轻轻点头、安心落灯；试听不增加招呼计数。自动回应还受原有 40 秒陪伴回应间隔约束，音频层另设 8 秒自动间隔、3 秒主动互动间隔，只有明确试听采用 650 ms 间隔。一次只保留一个主要声音，旧尾音约 35 ms 淡出，交接时最多两个短音源；最多缓存九个 PCM 缓冲，结束后断开节点，不启动音频专用动画帧。

暂停、后台、关闭角色声音和音量归零都会停止短音，异步恢复中的旧请求也会作废。暂停或隐藏时先淡出再挂起共享上下文，恢复时不补播尾音。安静陪伴中抑制自动声音，主动摸头、招呼和试听仍可回应；暂停时禁用试听。面板 data 属性公开 voice、rain、voice-volume、rain-volume、context、paused、hidden、quiet、plays、voices、kind、buffers，用于检查播放联动，不暴露内部应用对象。

~~~powershell
npm run voice-preview
~~~

当前导出文件位于上级 assets/sound/soft。`voice-preview.wav` 依次为开心、害羞、安心，使用与页面默认音量相同的增益；独立 WAV 为 48 kHz、16 bit 单声道，没有雨声。`signal-checks.json` 记录原始合成信号的峰值、RMS、直流偏移和相邻样本变化。初版文件保留在 assets/sound，未覆盖。听感与手机扬声器效果仍需实际试听判断。

## 摸头与安静眯眼

命中身体网格且角色局部 y ≥ 1.82 的区域用于轻抚，随角色平移、旋转和缩身后的矩阵转换。鼠标不按键时，需要在头部连续缓慢来回滑动；头部按下/单指接触后，一次明确的慢滑也可触发。头顶手势不再移动角色；身体与衣角保留 7 px 拖动阈值，提灯与背景保留原操作。轻点头顶、按钮“摸摸头”和画布 H 键继续可用，H 按住连发无效。摸头动作至少间隔 2.2 秒，身体拖动、暂停、隐藏或多指期间不触发。

HeadStroke 仅处理真实 pointermove 的屏幕坐标和时间戳，按投影头部大小设置约 10–22 px 的有效行程。鼠标悬停需完成两段反向行程且至少 280 ms；主动接触时需约 1.25 倍行程且至少 220 ms。小于 1.5 px 的抖动不累计；快速跳跃、明显快划、超过 700 ms 的断续会重启识别。离开头部、按下/抬起、取消、丢失捕获、多指、页面隐藏、暂停与视口变化都会清掉未完成手势。头部捕获期间允许 pet 动作进入原有缩身/脸红/音频链路，不改变身体目标位置或镜头。

OrbitControls 0.186.1 会写入内联 cursor:auto，初始化后移除这个内联值，由命中区域的 CSS 管理光标。头部使用本地手绘 pet-hand.svg，身体 grab、拖动 grabbing、衣角 ns-resize、提灯 pointer。头部鼠标提示跟随指针，触屏不显示悬浮提示。画布 hit-target 和可见 gesture-hint 用于检查实际命中与提示，读取不需访问内部场景对象。没有额外动画循环或音频请求。

CompanionMotion 在场景模拟时间内计算约 1.8 秒的 tuck 包络：快速缩身眯眼，缓慢恢复。幽灵整体轻微压低、放宽、低头和收手臂，提灯与雨水碰撞随同一角色矩阵移动，不改材质。摸头只更新当次回应，不增加招呼计数或创建任务记录。待机约 18–34 秒后缓慢眯眼约 2.8 秒；输入或新的回应会唤醒它，拖动期间不启动，不触发音频。所有动作随暂停与隐藏冻结，无额外动画循环。画布新增 pets、companion-tuck、companion-squint、companion-eyes 属性便于检查。

`npm run voice-preview` 额外导出 pet.wav（约 0.795 秒），三段组合试听顺序不变。摸头、招呼和安静模式仍尊重角色声音开关与音量；默认静音，只有主动开启后会叫。

摸头的脸红使用 2.6 秒独立缓动包络，略晚于缩身消退；开始和结束为零，暂停与重置遵循场景时钟。CheekBlush 将两片柔边椭圆合并为一个小网格，以原布料三角形的重心坐标插值贴合当前顶点/法线，沿法线抬高 0.009 避免闪烁。材质沿用斗篷的粗糙度和织物光泽，暖粉色最大透明度 0.30，没有额外光源、发光或屏幕滤镜。原主体材质不改动，双颊只在脸红时绘制；纹理在本地生成，离开场景会释放。画布 companion-blush 表示当前材质透明度。页面初始提示也会说明直接轻点头顶的操作。

## 顺着手轻蹭与持续安心

完整轻抚开启一个连续会话，后续有效移动更新手相对头顶的位置及滑动方向，经约 0.2 秒缓动跟随。按相机的右、上、前轴施加小幅姿态偏移：横向倾斜上限约 3.7°，纵向约 1.7°，前蹭约 0.017–0.033 场景单位。换视角后仍朝屏幕中的手偏过去，不写入身体拖动目标或弹簧。原有雨滴碰撞、脸红与提灯跟随角色矩阵。

有效来回需不断续上：最近一次完整行程不超过 1.4 秒，最近有效位移不超过 0.25 秒，才累计连续轻抚时长。约 1.4 秒后开始缓缓放松，连续约 3–4 秒明显眯眼；停手后舒缓睁眼、回正。未完成的抖动、静止按住、悬停和断续不能积累安心。缩身后原头顶附近保留小范围椭圆接触余量，避免角色自己的动作把手势打断；离开余量、快划、多指、取消、暂停、隐藏、尺寸变化和重置均结束会话。新一次按下仍严格按真实网格区分头部与身体。

一段持续轻抚只触发一次原有害羞缩身、脸红与 pet 声音请求，后续不反复缩身或鸣叫。重新开始的轻抚叫声另设 12 秒间隔，安心阶段无额外音效；按钮/H/轻点及招呼沿用原音频限制。持续轻抚时只维持约 0.066 的淡腮红透明度。所有缓动沿用模拟时钟与既有动画循环，暂停冻结当前姿势，恢复后不继承旧输入。新增只读画布属性 companion-stroke-x、companion-stroke-y、companion-nuzzle、companion-comfort，不新增依赖或绘制对象。

## 停手后的轻轻目送

自然结束与取消分开处理。鼠标移出头部或画布时，从最后头部采样点到离开点取得方向；手指抬起没有额外平面位移时，用最后有效轻抚方向。只有已识别的轻抚会话可以启动目送，不新增场景互动或声音事件。没有 pointerup/leave 的静止停手超过约 0.55 秒，也会沿最后手的位置目送一次；转向时的小暂停不结束会话，后续离开事件不重复启动。

CompanionMotion 以约 0.3 秒柔和进入，稍停后在约 2.6 秒包络内回落，尾部继续缓动消退。眼睛偏移配合原有视线逻辑，身体附加的屏幕方向偏头仅约 1°，小于轻抚时的动作，不再前蹭。安心眯眼会缓缓睁开。自然结束清掉旧的悬停注意力，目送期间不反复采样成持续凝视，结束后恢复自然待机。背景中指针的旋转影响也随注意力回落，避免留下固定偏头。

重新轻抚、主动动作、抓取身体、键盘移动或操作镜头会收回目送。取消、多指、暂停、隐藏、尺寸变化和重置仅结束输入；暂停保留当前姿势，恢复后平滑收回，重新载入不补动作。只使用现有时钟、网格与材质。画布新增 companion-farewell、companion-farewell-x、companion-farewell-y 只读属性；它们表示目送的当前缓动权重与方向，不写入陪伴记录或音频状态。
