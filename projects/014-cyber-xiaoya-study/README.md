# 014 · 赛博小雅：真人拟人化效果与模型依赖研究

原视频中的赛博小雅把语言回答、自然声音和真人形象组合成互动角色，让交流具有更具体的在场感。本研究从演示效果出发，解释能力、原理、价值和扩展方向；原作公开源码尚未确认，不能将它当作已经核验的完整开源库。

**模型决定表现上限，工程决定交互是否顺畅，产品决定用户是否愿意持续使用。**

- **能力**：演示呈现真人风格人物、声音与直播互动场景；完整的待机、说话、打断、恢复倾听仍需连续实测。
- **原理**：VAD/ASR负责听，语言模型负责想，TTS负责说，专门的视觉模型负责脸、嘴型、表情与动作。工程把输入、流式生成、音画同步和轮次取消连起来。
- **价值**：真人形象与自然回应可能增加在场感、降低开口门槛；集成工程降低做成可用产品的成本，实际留存与收益仍需验证。
- **扩展**：先用线上服务验证真人闭环，再研究口语陪练、知识讲解、直播互动，以及可管理的角色记忆、模型替换和成本监控。

## 最重要的发现

转帖列出的VAD、ASR、语言模型和TTS主要解释语音链，**没有解释真人画面如何生成**。原封面的Vidu S2标注提示必须单独研究视觉层，不能直接推导四个模块在15GB显存内完成全部真人表现。

真人外观、眼神、表情、嘴型与身体动作主要依赖模型和素材。工程负责输入、生成、同步、取消与恢复；接入代码和漂亮界面不能补出模型本身缺少的能力。纯本地、显存和商业收益保留为待确认。

## 本地阅读

需要Node.js 20+，无需安装依赖或配置密钥。在本项目web目录运行：

~~~powershell
npm run build
npm run dev
~~~

页面默认静态展示图解和研究，提供原视频来源及按需播放入口，不会自动调用模型、录音或产生模型费用。图解可由scripts/make-overview.mjs重新生成，使用已配置的文档运行时中的sharp，仅用于SVG排版导出。
