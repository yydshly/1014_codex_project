# 同一处地点，不同的事情

`0.4.0` 将“随机去哪里”和“到了这里遇见什么”分开。仍有六处地点，每处有自己的内容池；地点再次出现时，会从该处尚未遇见的内容中选择另一种处境或事件。进去以后保持稳定，不把用户的行动结果交给概率。

## 这版实际能变什么

| 地点 | 场景内的变化 | 怎样保证差异有意义 |
| --- | --- | --- |
| 邮局 | 六位人物与六种寄信心事，每人三个专属回应和对应回访卡片 | 人物、处境、草稿、回应、寄出的句子与后来作为一整组选择；不只替换姓名 |
| 修补铺 | 店主自己的旧物、送给第一次上学的外孙、音乐教室的委托，三种木鸟处境 | 同样选铃，选择的理由、当场回应与后续各不相同 |
| 候车亭 | 雨中船灯、雨歇归鸟、云缝里的光，三种环境与自然变化 | 天气和事件相容，雨停仍有檐水；不再每次都等到船灯 |
| 天台 | 风铃与纸签、落下的纸飞机、对楼亮起的窗灯 | 纸飞机出现后可以展开阅读，其他事件可只观察；留下的纸签分别保存在那一次 |
| 温室 | 六条可解光路，改变光源方向、镜子位置与目标植物位置 | 镜子反射规则不变，光路实际变化，所有朝向组合都经过可解性检查 |
| 星图台 | 三种天空光线；目标方位和初始星环位置继续按本次种子变化 | 光线只提供氛围，真正需要操作的目标和起始位置也会变化 |

邮局的六组内容如下，均为虚构故事。

| 人物 | 正在经历什么 | 用户的回应可以改变什么 |
| --- | --- | --- |
| 小屿，年轻旅人 | 第一次离乡，给家里报平安 | 写眼前风景、说想家，或陪他自己写下末句 |
| 阿岚，厨师 | 在外工作四年，终于准备回家 | 写一顿饭、承认重逢的紧张，或接上奶奶最常问的话 |
| 小满，学生 | 弄坏姐姐的旧相机，不知怎么道歉 | 承认与补救、记起相机的重要，或决定当面说清楚 |
| 周老师，教师 | 想向多年前替她留灯的人说谢谢 | 写具体细节、简单表达感谢，或留一个再见面的邀请 |
| 阿禾，花店店主 | 想重新联系很久没见的朋友 | 分享今日小事、不催促的邀请，或直接表达惦记 |
| 林姨，退休后学画的人 | 给老同事写告别卡，也开始新的日常 | 写新打算、记下一起度过的日子，或约一个新的见面方式 |

六人共有 18 条可选择的回应路径，各自连接到相应的信和后续。内容定义集中在 `web/src/variations.js`，以后可以新增成套内容；已有内容 ID 保持稳定，以免改写收藏中的故事。

## 三种继续方式

- **走向下一扇门：** 继续在所选范围内随机目的地，再选择那里的本次内容。
- **同一场景，再遇见一次：** 地点不变，创建新的一次，抽另一种心事、事件或布局；邮局的按钮写作“邮局里，再遇见一个人”。
- **从手记回来：** 回到原来那一次，保留人物、选择、纸签、已发生事件和解题进度。完成过的故事显示对应后续。

重新遇见会创建独立记录，不覆盖旧的那一次。门前已经选择好的内容在刷新后不重抽；回访不消耗待开的门。主动点“还是去别的地方看看”，才放弃当前同场景入口，回到随机目的地。

## 内容抽取与兼容

地点和场景内内容分别维护候选池。一个场景内先经历完当前内容，再补回；有其他内容可选时避开刚遇见的那一种。星环目标与布局附带固定种子，进入后不因操作变化。

旧 `0.3` 手记会对应回原来的第一组内容：邮局仍是初次离乡，候车亭仍是船灯，天台仍是起风，温室保留原来的左右光路。不会把旧信变成新人物，也不会清空选择。

安静场景在事件发生前只描述当前天气与气氛，不提前揭露将出现纸飞机、鸟群或窗灯。事件自然发生后，文字与手记再记录它。

这是可扩写的有限内容池，不是无限世界生成器。本轮先验证：同一场景中的人物处境、参与内容和后续变化，能否支撑再次遇见。实际体验是否持续有新鲜感仍待用户反馈。
