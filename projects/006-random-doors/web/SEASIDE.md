# 旧版 3D 海边候车亭说明

本页保留截至 `0.2.0` 的 3D 候车亭操作。`0.3.0` 主入口已切换为连续开门，本体验保留在独立的 `seaside.html`，不参与六个简化场景的抽取。

本目录实现“安静停留”的海边候车亭本地原型。推门进入后，可以看海、坐下、接住檐水，等待船灯从海雾中出现。使用 Three.js 实时渲染，不需要模型服务、外部素材接口或密钥。

当前版本为 `0.2.0`：海面使用方向波与天空反射，天空加入缓慢移动的云层；接雨手势包含指节、掌纹与从画面边缘伸入的衣袖；船只、灯光与倒影平滑出现和消失。相机构图随窗口比例调整，在较窄的桌面侧栏中也能看到掌心和水盘。

## 本地启动

环境要求：Node.js 22.12 或更高版本，支持 WebGL 2 的浏览器。

在本目录运行：

```powershell
.\start.ps1
```

脚本会在首次运行时安装锁定的依赖，并启动本地服务。也可以分别执行：

```powershell
npm ci
npm run dev
```

打开 [旧版 3D 海边候车亭](http://127.0.0.1:4178/1014_codex_project/006-random-doors/seaside.html)。服务只监听本机，端口为 `4178`；关闭启动它的终端后需要重新运行。

## 操作方式

| 动作 | 操作 | 反馈 |
| --- | --- | --- |
| 进入 | 点击“推门，去看海” | 木门转开，视角走入候车亭 |
| 环顾 | 拖动画面 | 在有限范围内调整视线 |
| 坐下与站起 | 点击对应按钮，或画面聚焦时按空格 | 视角平滑降低或升高 |
| 接雨 | 按住 R，或按住“按住接雨”按钮、檐水热点 | 手伸到水滴下方，水在掌心散开；松开后重新落回水盘 |
| 键盘操作接雨按钮 | 聚焦按钮后按空格切换，再按一次收手 | 可在无需持续按键时观察接雨 |
| 再开一扇 | 点击“再开一扇门”后再次推门 | 默认从另外两种天气中随机选取一种 |
| 比较天气 | 打开“风景与声音”，选择下一次天气，再点击“去下一次遇见” | 可以指定黄昏细雨、入夜微雨或雨歇薄雾；选择“交给偶然”恢复随机 |
| 看船灯 | 进入后自然等待 65 至 85 秒 | 船灯出现并沿海面缓慢移动约 72 秒，与坐下或接雨无关 |
| 提前看船灯 | 在“风景与声音”中点击“让船灯早些出现” | 提前查看当前片段，不改变收藏里的自然出现时间 |
| 声音 | 点击顶部“声音 关”开启，在设置中调节音量 | 本地合成海浪、雨与落水声；默认关闭 |
| 收藏与回访 | 点击“留住这次遇见”，刷新后选择“回到收藏的那片海” | 在当前浏览器保存天气、本次遇见的种子和座位状态；重新开始本次停留的事件时间 |

雨歇薄雾没有空中降雨，屋檐仍有较慢的残留滴水，接雨互动依旧有效。两分钟是脚本的参考长度，原型不会在两分钟结束时强制退出。

## 随机与稳定性

天气在创建一次遇见时确定，进门后的动作不会重新抽取。三种天气分别影响天空、海色、雾、雨量、灯光与声音；船灯延迟同时确定。默认连续随机会避开上一种天气，主动指定和回访收藏则尊重用户的选择。

切到后台时暂停体验时间并淡出声音；回到页面后继续。收藏保存在浏览器本地存储中，仅保留最近一次，不上传。

## 检查与构建

```powershell
npm run check
npm test
npm run build
```

`check` 检查语法，九项测试覆盖天气选择、事件定时、收藏恢复，以及不同窗口比例和坐姿下的接雨构图；`build` 生成 `dist/`。浏览器交互检查见[验证记录](../VERIFICATION.md)。

## 文件与依赖

| 文件 | 职责 |
| --- | --- |
| `src/main.js` | 进门、操作、设置、收藏与页面可见性 |
| `src/experience.js` | 固定天气组合、随机选择与船灯时间 |
| `src/scene.js` | 候车亭、门、手、雨滴碰撞、水盘与船只 |
| `src/view.js` | 随窗口比例、坐姿与接雨状态调整相机构图 |
| `src/shaders.js` | 实时天空与波动海面 |
| `src/audio.js` | Web Audio 合成声音 |
| `src/style.css` | 文字、操作入口与设置面板 |

Three.js 固定为 `0.186.1`，Vite 固定为 `8.3.4`，依赖图由 `package-lock.json` 固定。场景几何、纹理、着色与声音为本项目新增实现；第三方库的来源与许可证见[说明](public/licenses/THIRD_PARTY_NOTICES.md)。
