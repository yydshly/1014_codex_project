      MAKE YOURSELF AT HOME
      
    欢迎来到 Agent 工作室。
    
      
    
        每个人物代表一种分工。开始一次协作，观察真实事件如何驱动人物、语音、交接和产物。
      
    
      
    
        
    协作演示
    
        
    
          预设模式包含并行审阅与验证、返回修改和交付；语音由 MiniMax
          预先生成。真实模式会调用六位角色 Agent 生成并检查方案。
        
    
        
    人物与产物
    
        
    
          点击人物查看身份、状态和产物。发言按顺序播放，可暂停、跳过或停止。
        
    
        
    自由观察
    
        
    拖动旋转，滚轮或双指捏合缩放；方向键调整视角。
    
        
    认识住客
    
        
    点击角色、名字或右侧头像，再选择「从 TA 的视角出发」。
    
        
    第一人称
    
        
    
          WASD / 方向键走动，Shift 跑步，拖动环顾，Esc
          返回；手机使用屏幕方向键。
        
    
        
    执行中接管
    
        
    
          点击人物进入工作台，查看代码、修改差异和执行命令。暂停回放只暂停场景；暂停执行会在当前命令收尾后拦住后续工具步骤。
          暂停后提交修改意见，角色会语音回应，必要时邀请伙伴到白板讨论；白板同步展示修改方案、分工与验证方法。接管意见与方案保留在本轮记录中；点击“按方案继续”后才回工位执行同一任务。
        
    
        
    夜晚的声音
    
        
    点播放器开启原创合成 lo-fi。切换雨夜 / 月夜会改变窗外和环境声。
