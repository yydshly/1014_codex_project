# Agent 小屋 Web

Three.js + Vite 前端，以及在开发 / 预览服务器内运行的本地 MiniMax 代理。静态构建支持预设协作；真实 Agent 和动态语音依赖本地服务。

## 启动、配置与检查

需要 Node.js >=22.12.0。

```powershell
npm ci
npm run dev
```

入口：<http://127.0.0.1:4175/1014_codex_project/003-lofi-room/>。Windows 可执行 `./start.ps1`。服务默认仅监听本机。

默认入口是原来的夜半小屋。使用页顶入口进入 `?view=workspace` 的 Agent 工作室或返回 `/1014_codex_project/` 项目首页；首页读取根 `projects.json`，也能打开 001、002 已有构建。两个场景共用 003 的模型、依赖和编号。

预设模式可直接使用随项目提供的十段 MiniMax MP3。启用真实模式时，复制 `.env.example` 为 `.env.local` 并填写 `MINIMAX_API_KEY`，或设置 `MINIMAX_ENV_FILE` 引用已有配置。支持环境变量覆盖，修改配置后重新启动服务。

| 配置 | 默认 / 用途 |
| --- | --- |
| `MINIMAX_API_KEY` | 必需，仅服务端读取 |
| `MINIMAX_ENV_FILE` | 可选，已有环境文件的绝对路径 |
| `MINIMAX_BASE_URL` / `MINIMAX_API_BASE` | `https://api.minimax.cn`；仅接受官方 HTTPS 域名 |
| `MINIMAX_TEXT_MODEL` | `MiniMax-M3` |
| `MINIMAX_TTS_MODEL` | `speech-2.8-turbo` |
| `MINIMAX_VOICE_MORI` 等 | 可覆盖各角色系统音色，完整列表见模板 |

```powershell
npm run check
npm test
npm run build
npm run preview
```

预览启动后另开终端运行 `npm run smoke`，检查编号子路径、JS / CSS / 图片、许可和十段录音。

`npm run voices` 根据 `shared/workflow.js` 的台词重新生成缺失录音，已有文件会跳过；需要有效配置并会产生 MiniMax 服务调用。录音清单记录模型、音色、文本与生成日期。

## 目标、白板与人物对话

- 「目标看板」管理目标名称、具体内容、验收要求与每轮历史；当前浏览器本地保存，支持导出全部目标记录。每个目标最多保留八轮交付，执行中不可切换目标。
- 书架前的落地白板显示目标、角色状态和讨论意见，窗边电脑显示共享产物与交接记录，桌上另有验证电脑。可直接点物体，也可点顶部入口打开详情。
- 白板意见与真实对话结果会保存到目标，下一轮将验收要求、最近五条反馈和上轮交付摘要传给每个角色。它们不会改写正在执行的一轮。
- 「对话」支持一对一和双人讨论。真实模式会读取当前目标、已有产物与伙伴的上句话；预设模式只播放标明的固定对话。短语音最多 160 字，完整文字保留在对话记录。
- 提交对话后自动收起文字窗，伙伴走到白板前再发言；再次点对话入口可查看同一段记录。支持暂停播报、继续、跳句与停止。
- 进行中的工作回放会在对话开始前暂停，结束后可手动继续；两条声音不会同时播放。关闭对话文字窗的 × 会停止对话，「看人物讨论」则继续。
- 完成交付后，白板上的验收要求由使用者逐条确认，再点「确认验收」。修改目标内容或要求后，需要重新开始新一轮，历史产物仍保留。
- 刷新只恢复目标、已收到的事件和产物，不恢复模型进程。未完成的一轮标为「待继续」，下一次开始新建一轮。

## 协作与房间操作

1. 选择预设流程或真实 Agent，填写目标，点击「开始协作」。预设流程固定演示一次返工；真实流程根据角色检查结果决定是否返工，最多一轮。
2. 默认收起侧栏，让人物推动过程：白板前集结、到工位操作、电脑椅侧入座打字、当面交流与递交、白板前汇报。审阅员与验证员同时到各自工位。快速返回的模型结果也会等人物到位，并至少工作四秒，再展示产物。
3. 「暂停回放」冻结走动、工作计时、交接与播报；真实模型在服务端可能继续生成。「停止」取消本轮请求和动作等待，清理播报与待处理事件，保留已有产物。临时讨论期间，原交接与回放计时保持暂停；继续时先返回工位，再恢复播报。
4. 点产物打开全文；点人物查看任务、试听音色和进入其视角；「导出」保存本轮 JSON。
5. 自由观察：拖动旋转、滚轮 / 双指缩放；「关注发言者」让视角跟随工作区域，拖动后停止自动跟随。漫游：WASD / 方向键移动、Shift 跑步、拖动环顾、Esc 返回。工作室采用独立观察者，人物持续工作；原房间保留从所选住客视角出发。手机提供方向按钮与任务面板入口。

语音失败时展示原因并保留字幕；不会替换成浏览器系统语音。角色模型失败时终止并保留产物，不会伪装成预设流程成功。页面切到后台时自动暂停回放。

分工播报结束后，无关人员离开白板。`HOME_SPOTS` 定义个人活动：整理笔记、电脑资料、写手记、地垫阅读、沙发阅读与休息。交接只召集双方，完成后短暂停留以衔接下一项任务；没有新任务就回自己的位置。整轮交付后六人散场。个人活动独立于任务状态，不会产生虚假进度；临时讨论期间，未参与且正在休息的人可以继续自己的活动，已暂停的任务操作保持冻结。暂停和停止仍同时控制这些人物动作。

当前六个 Agent 仅生成、检查和汇总方案。角色工具 `publish_result` 提交结构化产物，无代码执行、网络搜索或文件修改权限。

待命活动由 `ambient-life.js` 编排：每个人先在个人位置停留，再错开喝水、站立伸展或短距离慢走；活动后回原位置停留 25–53 秒。最多两人同时离开个人位置，饮水角独占，路径继续避开家具。喝水包含伸手拿杯、举杯、轻微倾杯和放回；任务或讨论优先打断活动，持杯者先放杯再走。活动计时跟随场景暂停；减少动态效果时只回个人位置，不再自动走动和伸展。

`room-social.js` 在此基础上编排两人互动：慢走路过空闲伙伴时暂停路线、挥手招呼和回应；休息时选择空闲且最近未交谈的伙伴，近处原地聊，远处走近后再聊。对话只占用这两人，结束后恢复原路线、坐姿或个人活动；同一对人物有冷却间隔。工作、用户发起的讨论、停止与减少动态效果可以取消闲聊，不会保留过期话音。

人物语音使用单一发言权：主任务播报、工作核对、闲聊与用户讨论不会叠音。页面下方的「开启房间语音」提供浏览器需要的首次播放手势，之后可随时关闭；「角色语音」控制全部角色播报。暂停会同时冻结对话计时、声音和人物；工作回应被手动讨论打断时保留原话，回到原位置后继续。首次未开启声音时仍展示字幕。

接收交接后，人物会语音确认；开发员和记录员开工前主动与实际输入的提交者核对。预设模式播放准备好的工作短句；真实模式读取该轮交接的任务、产物标题和摘要，实时合成两人的对齐发言。此处复用已有产物，不额外调用文本模型生成新结论。

`public/voices/room/` 的 36 段短句已随构建提供，来源见其 `manifest.json`。`npm run room-voices` 按 `shared/room-lines.js` 生成缺失录音，需要 MiniMax 配置且产生语音服务调用；已存在的文件跳过，短暂限流会有限重试。

## 本地接口

| 接口 | 行为 |
| --- | --- |
| `GET api/status` | 返回配置是否可用、模型与音色，不返回密钥 |
| `POST api/run` | 接受目标与 live 模式，返回 NDJSON 事件流；每次限一轮真实协作 |
| `POST api/discuss` | 接受目标、问题、人物、验收要求与产物摘要；两位角色依次回应，第二位读取第一位发言，返回 NDJSON |
| `POST api/speech` | 按角色音色合成 MP3；文本限制 500 字，有限并发和内存缓存 |

接口仅接受本机 Host 与同源请求。模型产物经过 Zod 和协作层双重校验；页面使用文本渲染，模型内容不作为 HTML 执行。客户端断开会取消模型任务。

## 部署

构建输出 `dist/`，基础路径固定 `/1014_codex_project/003-lofi-room/`。静态发布时把完整产物复制到 `_site/003-lofi-room/`，遵循仓库 [部署约定](../../../docs/DEPLOYMENT.md)。GitHub Pages 无法运行本地接口，真实模式自动禁用，预设流程和录音仍可使用。

若要公开提供真实 Agent，需要另行部署服务端，并补充认证、预算与访问控制；当前服务面向本机演示。尚未发布线上站点。
