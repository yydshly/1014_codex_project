01 / 理解结论先行

核心价值，是模型
生成与修改 3D 的能力。

这次验证的是：模型能够理解视觉目标，把物体、空间布局和材质要求转化为代码，并根据渲染反馈继续修改。

具体实现是模型通过代码使用 Blender。模型负责理解、规划和编写脚本；Blender 负责执行几何操作，计算材质、光照和最终图像。

这里的“模型生成 3D”指通过代码构建场景。本次没有调用直接输出三维网格的专用图生 3D 模型。

02 / 过程从图像到空间

一张图，经过四步落地。

图片提供视觉目标，三维结构由脚本重新构建。

本次新生成

先有自己的视觉目标。

创作紫藤、水池、月门和天球仪组成的暮色庭院。生成时没有传入前一轮作者的图片，完整提示词已保留。

圆门 → 环形石块天球仪 → 交叉金属环池水 → 网格与反射材质
视觉理解 → 代码

把“看起来是什么”，变成“怎样搭出来”。

估计比例、坐标和机位，再编写普通 Python 建模代码。图中不可见的背面和连接结构由本实验补建。

真实三维

换个角度，结构仍然成立。

圆门、桥、树、金属环都有网格几何。工程重新打开后，从侧上方渲染；参考图没有作为背景或投影参与成像。

观察 → 调整 → 再渲染

生成一次，还需要继续判断。

修正相机高度、被裁切的灯笼、过暗的远山和拱廊结构，再改善树皮与材质。这是多轮定向调整的结果。

05 / 价值从一张成图，走向可操作的结构

价值，在于后续还能怎么改。

当目标需要新的机位、结构变化或交互，模型构建三维的能力才有更大的用处。

↗

换机位

一个场景，多个镜头。

重新安排相机与灯光，输出远景、近景、环绕或镜头预演，保留同一套空间关系。

可用于：内容制作、镜头预演
↔

改结构

从改画面，到改物体。

调整石门尺寸、移动树、改桥与水池的布局，再统一渲染比较不同方案。

可用于：空间原型、产品与结构展示
◇

接交互

让空间承载操作。

在后续工程中加入浏览、点击、状态切换或任务入口，让三维物体与真实功能关联。

可用于：虚拟展览、教学、工作空间、游戏
