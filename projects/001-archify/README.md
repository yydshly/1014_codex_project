## 为什么研究这个项目

Archify 由 AI 编程代理把描述或代码库整理为结构化图解，再通过渲染与校验生成交互式 HTML。查看生成结果不需要安装 Archify；生成新图仍需要代理分析内容，或提供符合格式的图解数据。

选择它的理由：

- **与你的研究工作直接相关**：以后每个 GitHub 项目都可以补一张结构图和一条核心调用路径，帮助读者理解项目。
- **展示范围容易收敛**：先围绕一个代码库做图解，提供节点说明、主题切换与导出，再研究其他功能。
- **网页方案可行**：固定版本的示例 HTML 没有外部脚本或外部样式表引用，适合进一步验证静态站点展示。
- **有明确的产品假设**：面向需要介绍项目的海外开源维护者、技术写作者和小型开发团队，尝试代码库导览与新人入门文档。

上述产品方向是本次研究提出的假设，尚未验证需求、付费意愿或收入。

## 本地运行

在本目录的 `web/` 下启动：

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

启动脚本会选用 Node.js 24.19 或更新版本，构建中英文图解并启动本地预览。首次运行需要 Git 和网络获取固定版本上游；后续使用项目独立的 `.cache/upstream` 缓存。不会安装全局 Skill，也不会改动系统 Node.js。

运行后访问：<http://127.0.0.1:4173/1014_codex_project/001-archify/>。首次图解以 Archify 自身的 `render architecture` 分支为研究对象，提供结构图、生成链路、组件讲解和固定版本源码链接。详见 [Web 运行说明](web/README.md)。

已检查节点联动、完整路径、中英文切换、主题联动、源码表和窄屏容纳。内置浏览器的下载完成事件无法取得，未将文件下载计为成功；上游 SVG / PNG 导出回归检查已通过。
