PRACTICE / ACCUMULATION & ENTRY POINTS

个人主页的直接参考价值

沉淀包含事实、判断和行动结果。入口同时服务自己与读者：自己能找回旧研究，读者能从摘要进入案例、方法和产品。复习放在下一次决策发生之前，反馈回来之后再更新。

给自己 / 研究资产

每个项目留一张可回看的记录卡

  • 起点：为什么研究，来源和固定版本是什么。
  • 判断：核心能力、适用条件、值得参考什么。
  • 实践：做了什么，结果和限制是什么。
  • 下一步：继续、搁置或待验证，什么证据会改变判断。
给读者 / 清楚的入口

让访问者知道从哪里继续

  • 第一次来：先读摘要，理解你关注什么。
  • 想了解能力：查看案例、结果和原始依据。
  • 想实际体验：进入工具演示和方法工作台。
  • 有相似任务：未来可从产品或明确的联系入口继续。

联系入口是自己的主页后续设计方向；当前研究页未设置真实业务联系或收款流程。

给下一次行动 / 复习更新

做之前回看，做之后记录

  • 开始相似项目时：复用资料，检查旧结论是否仍成立。
  • 实践完成时：记录结果、时间与关键限制。
  • 取得反馈时：补充真实任务、失败、复用或交易证据。
  • 定期回顾时：更新摘要、入口和下一步，保留修订依据。
沉淀与反馈的完整路径

研究 → 实践 → 记录 → 展示 → 接触用户 → 获得反馈 → 更新研究

04 / AI DISCOVERY LOOP

让下一步调查，由证据决定。

方法演示

输入可以是宽泛的探索范围。AI 逐步发现角色、观察任务、提出假设、寻找独立证据与反例，并留下每次转向的理由。

AI 负责什么

扩大观察，发现联系，
保留不确定性。

探索

提出角色和任务候选，寻找聚集地，识别观察盲区。

理解

从上下文提取行为、障碍、代价，区分发帖者和回复者。

追查

从真实用语扩展查询，找相似经历和不同解释。

修正

结合反例决定继续、转向或搁置，记录判断依据。

核心验收

没有输入具体痛点，也能发现值得调查的人群与问题，并解释：从哪条线索出发，为什么走到这里。

展开证据记录规则与误判防护 ＋

来源与原话

保留原始链接、位置、读取时间、发布日期依据、片段完整度；标题或搜索摘要不冒充完整正文。

独立性与去重

先合并同帖与转载，再核对是否同一人的重复表达；一串回复不能直接折算成若干独立客户。

上下文与角色

区分发帖者、回复者、工具推荐者；对广告、联盟推广、模板内容和缺失信息标注不确定性。

缺失与变化

记录被拒绝、读不到和已删除的来源；后续接入应支持更新、失效与删除处理。

事实与推断

“每周两小时”须有原文；没有耗时、预算和效果，就明确记为未知，不补数字或夸大强度。

反例与验证

已有办法有效时保留；点赞、抱怨、任务标价、AI 评分均不足以单独证明付费市场。
