# 009 · 个人主页启发与需求发现产品探索

JasonZhu.AI 是个人品牌网站：以博客、工具推荐、项目和服务展示能力，通过订阅、资料与联系提供下一步入口；固定源码还包含来源采集、AI 筛选摘要和快讯发布。对我们的直接启发是**做好自己的研究沉淀、入口引导与复习更新**，让每次实践成为下一次行动和读者理解的依据。

**研究 → 实践 → 记录 → 展示 → 接触用户 → 获得反馈 → 更新研究。** 做之前回看，做之后记录，有反馈就更新。个人主页承载研究、案例与产品；用户的真实任务和反馈继续修订研究，触达与转化效果需要实际验证。

进一步可把上游探索产品化：从宽泛活动发现人群、任务和问题，借助 AI 追查原始证据、已有办法与反例，再扩展到持续观察、机会研究、需求验证、最小网页产品与专题研究服务。009 用独立中文网页整理这条路径，包含 27 个来源入口、行为信号、方法、证据边界和产品规划。

现已增加 OpenAI 自动探索第一版：从宽泛领域连续执行发现人群、寻找问题、追查证据，并展示公开查询、来源、反例与最终判断。首轮真实结果见 [实验001](EXPERIMENT-001.md)。原有平台目录、研究方法和计划继续保留。

2026-10-19 补充[理解全景图](assets/understanding-map.svg)与[完整说明](UNDERSTANDING.md)：原库能力 → 个人主页的沉淀、入口与复习 → 思考演进 → AI 发现方法 → 已做探索 → 产品扩展价值。网页增加五项理解摘要、沉淀与入口方法、独立缩放阅读器及 SVG / PNG 下载，区分源库事实、我们的推导、本地实测与未来假设。

## 查看网页

需要 Node.js 22 或更新版本，以及已安装并登录的官方 Codex CLI。当前可使用本机正常登录执行，无需另配 API Key；运行消耗现有账户额度。静态浏览不调用模型。

```powershell
cd projects/009-demand-discovery/web
npm run dev
```

打开 [009 本地网页](http://127.0.0.1:4182/1014_codex_project/009-demand-discovery/)。也可以在 Web 目录运行 `./start.ps1`；自定义端口使用 `./start.ps1 -Port 4183`。

## 网页内容

0. **理解摘要与直接收获**：源库能力、个人主页参考价值、沉淀与复习、已有实践和需求发现产品扩展；明确研究与用户反馈的完整路径。
1. **思考从哪里来**：从个人网站、作品展示与反馈，转向开发之前的需求发现；区分原站启发与本轮分析。
2. **平台地图**：27 个国内外研究入口，支持按关键词、六类来源、地区与接入条件筛选，保留核查依据与偏差。
3. **如何发现问题**：重复操作、工具补缝、外包、等待、返工、适配约束、放弃和变化八类观察信号。
4. **AI 如何探索**：三种起点、七步调查循环；根据证据决定继续、转向或搁置。
5. **证据与旧样本**：四层证据、两条复用自 004 的真实 Reddit 材料、现有办法与尚不能回答的问题。
6. **产品蓝图**：目标用户假设、网页使用路径、候选卡片、未来系统与能力边界。
7. **后续扩展**：来源覆盖、持续观察、机会判断、需求验证、产品落地与专题研究服务，附成立条件。
8. **探索工作台**：四种起点，可编辑边界和笔记、加入平台、本地保存、复制指令与下载 Markdown。
9. **来源记录**：完整文档、结构化目录、官方文档与原站版本记录。

“沉淀、入口与复习”章节还给出研究记录卡、读者进入路径和复盘触发点，说明研究怎样服务下一次行动。
