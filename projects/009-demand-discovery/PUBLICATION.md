# 009 · 公开研究档案与发布说明

整理日期：2026-10-19。网页以“个人主页的沉淀、入口引导与复习更新”为直接收获，以“需求发现与产品化”为进一步扩展。

## 公开内容

- `index.html#synthesis`：五项摘要，分别说明原库能力、直接参考价值、核心反思、已做探索与产品扩展。
- `index.html#accumulation`：研究记录卡、读者引导路径、复习与更新节点。
- `index.html#understanding`：全景图、SVG / PNG 下载和完整说明。
- `index.html#explore`：2026-10-15 已保存的真实 OpenAI 探索，含人群、问题、过程、来源和限制。
- `understanding.html`：可缩放的一图总览。
- `notes/` 与 `data/`：完整研究、原始引用、实验和结构化资料。

研究闭环明确写为：**研究 → 实践 → 记录 → 展示 → 接触用户 → 获得反馈 → 更新研究。** 需求工具再向上游寻找角色与任务，并通过真实任务验证后决定是否产品化。

## 构建与边界

统一入口 `web/build.mjs` 运行检查、10 项测试和公开构建，再检查 23 个文件、摘要、锚点、图像尺寸及资源。`mode.js` 明确公开与本地模式。公开档案不请求本地 API，不启动模型和轮询；快照丢失会显示失败，不回退到模型服务。

支持浏览、筛选、查看过程、计划与报告导出。新的探索需要本地 Node 服务和正常登录的 Codex；公开站点不持有登录状态，不提供托管研究后端。市场、独立性、付费及长期使用仍待验证。

发布走仓库已有 GitHub Actions 与 GitHub Pages，静态子路径 `009-demand-discovery/`。完整构建保留已发布项目，`dist/` 和 `_site/` 均不提交。

## 验证范围

本轮采用矢量图直接渲染检查、缩放逻辑检查、静态模式行为测试、完整站点构建，以及发布后的 HTTP、字节与来源文件核对。浏览器接入此前被 URL 安全策略拒绝，本轮不声称完成新的视觉点击验收。2026-10-19 已部署成功：35 个公网地址、34 份资源内容对照、77 个页内编号和 31 处锚点链接通过核对，保留既有五个项目。实际提交、工作流和公网结果已记录到 `deployment.json`。
