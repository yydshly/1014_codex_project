# 李白 vs 杜甫 · AI 说唱视频制作清单

生成日期：2026年10月15日
制作路线：先做一个小实验
选题：人物 A 李白；人物 B 杜甫

## 制作目标

先证明四条镜头能接起来。一个由 3–4 句组成的短片段，加一份镜头与问题记录。

## 逐步执行

1. 准备短歌与人物参考
   写 3–4 句歌词，用合规来源的歌曲或人声；准备两人的正面、半身图和同一场地参考。先听音频，再做画面。

2. 单独安排每句时间与镜头
   为每句标出起止，建立短实验的 clips.json 与 edl.json，或修改分镜脚本。不把 4 句歌词直接交给默认整期模板。

3. 只生成少量素材并审片
   例如四条各 5 秒。每次只给一句人声；先确认一条，再做剩余镜头。检查脸、道具、音轨、嘴型和侧脸遮挡。

4. 按歌曲拼接，记录能否接受
   用 FFmpeg 或熟悉的剪辑工具组装，加上字幕，记下需要偏移、重做或切反应镜头的位置，再决定是否扩大。

## 必备输入

- 核查后的典故、歌词和每句动作，区分史实与文学设定。
- 已挑选的歌曲或人声，以及每句起止时间。
- 两位角色的脸、服装、道具与共同场景参考。
- 逐句生成计划、剪辑表和明确的费用批准。

## 本次预算假设

- 生成素材总时长：20 秒（不是成片时长）。
- 规格：768P；仓库参考单价：$0.08 / 秒。
- 基础生成：$1.60；额外重做预留：0% / $0.00。
- 视频规划预算：$1.60 USD。
- 仅为按仓库内置单价计算的本地估算，非实时价格，不含音乐、图片、Claude 与本地计算费用；实际以服务方当期计费为准。

## 审片与验收

- [ ] 歌词、典故和双方回应已经确认。
- [ ] 人物、服装、道具在镜头间保持可接受的一致性。
- [ ] 每句人声未被模型改唱，延迟已检查。
- [ ] 人工看过嘴型与遮挡；音轨相似不作为口型准确的充分证据。
- [ ] 剪辑节奏、字幕与歌曲一致；重做前确认费用。
- [ ] 超时任务先按 task_id 查询远端状态，避免重复计费。
- [ ] 检查所用音乐、图片、视频的使用授权，发布时声明 AI 生成。

## 路线提醒

如果想尽量沿用原脚本，可先保留完整 16 + 18 句配置和歌曲，再只挑 A01、A02、B01、B02 测试；其余镜头不提交。
