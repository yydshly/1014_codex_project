# 四句小样的真实音频制作记录

2026-10-15 完成。四句原创娱乐对唱通过 MiniMax `speech-2.8-turbo` 同步语音接口实际生成，共 4 次请求，每句一次，没有付费重试。它是**节奏化 TTS＋原创程序合成节拍**，没有调用 Suno 或其他歌曲模型，因此只验证两位角色发声、按统一时间轴交接、配音驱动画面和混音的制作机制；尚未得到歌唱模型的旋律、押拍能力。

李白使用官方系统音色 `Chinese (Mandarin)_Unrestrained_Young_Man`，语速 1.18、音高 +1、情绪 happy；杜甫使用 `Chinese (Mandarin)_Radio_Host`，语速 1.18、音高 −1、情绪 calm。没有模仿或克隆现实人物声音。接口返回合计 `usage_characters=88`；未读取账单，实际金额待账单确认。

伴奏由本项目独立生成：100 BPM、4/4 拍、底鼓、军鼓、八分音符踩镲和简短低音。鼓声与低音全部由正弦波和固定种子噪声合成，没有取用外部音乐或采样。四句人声保持原句速度，未做时间压缩；每句加入前导和尾部静音，得到精确 4.8 秒的解码内容。

| ID | 角色 | 句槽 | 原音容器时长 | 可闻能量区间（全局） |
|---|---|---|---|---|
| A01 | 李白 | 2.400–7.200 秒 | 2.628 秒 | 2.862–4.783 秒 |
| A02 | 李白 | 7.200–12.000 秒 | 2.700 秒 | 7.655–9.638 秒 |
| B01 | 杜甫 | 12.000–16.800 秒 | 2.556 秒 | 12.459–14.316 秒 |
| B02 | 杜甫 | 16.800–21.600 秒 | 2.700 秒 | 17.269–19.241 秒 |

前奏和尾奏各 2.4 秒，完整混音为 24.000 秒。可闻能量区间按 −38 dB、最短 0.10 秒静音自动估计，属于剪辑辅助值，不能代替听感或口型审核。原音保留服务返回的 MP3 字节；容器时长包含 MP3 编码边界，解码时长另记在 `lines.json` 中。句槽 MP3 的容器显示 4.824 秒，实际解码内容恰好 4.800 秒。

## 产物

- `work/audio/raw/{A01,A02,B01,B02}.mp3`：未经转码的原始服务返回音频。
- `work/audio/{A01,A02,B01,B02}.mp3`：归一化后的人声＋静音句槽，可直接作为逐句视频输入。
- `work/vocals_final.wav`：统一时间轴上的人声，24 秒、48 kHz、单声道。
- `work/beat_original.wav`：原创合成伴奏，24 秒、48 kHz、单声道。
- `work/music_final.wav`、`work/music_final.mp3`：人声与伴奏完整混音，24 秒、48 kHz、双声道。
- `work/lines.json`、`work/grid.json`、`work/字幕.srt`：真实句槽、能量边界和字幕。字幕在检测到的人声结束后多保留 0.15 秒。
- `work/audio-run.json`：服务、模型、音色参数、耗时、接口用量，无密钥。
- `work/audio-qa.json`：时长、电平和音频 SHA-256，供后续生成追溯输入。

最终混音实测峰值 −4.4 dB，均值 −25.9 dB，没有数字削波。四条句槽都经解码样本数检查，均为 230,400 个 48 kHz 单声道采样（4.8 秒）；最终 WAV 为 24 秒。人声识别正确性和表现力仍需试听，不能由这些技术检查推断。

## 重跑

在本实验目录执行，复用现有原音，无网络请求：

```powershell
node scripts/audio.mjs
```

只重新计算时间边界和字幕，保留音频字节：

```powershell
node scripts/audio.mjs --metadata-only
```

在原音缺失时，显式添加 `--generate` 才会调用服务。使用进程环境的 `MINIMAX_API_KEY`，或通过 `--env-file` 指向已有配置文件。脚本不保存配置文件内容，不将 Key 写入产物或日志。已存在的原音始终复用，每句最多调用一次，接口失败即停止，不自动重试。

同步接口与音色依据：[MiniMax 同步语音文档](https://platform.minimax.io/docs/api-reference/speech-t2a-http)、[官方系统音色表](https://platform.minimax.io/docs/faq/system-voice-id)。本实验脚本为本仓库独立实现，调用方式参照 003/005 子项目的既有配置与请求结构。
