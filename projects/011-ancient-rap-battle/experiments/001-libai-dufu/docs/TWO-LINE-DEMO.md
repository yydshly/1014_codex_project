# 李白两句生成实测版

`final/libai-two-line-demo-v1.mp4` 是独立的两句素材预览，只包含李白 A01 与 A02 两条真实生成视频。它不表示杜甫镜头或四句完整流程已经完成，也不替换四片组装和发布闸门。

时间轴为 14.400 秒：2.4 秒李白单人参考图片头、A01 原片 4.8 秒、A02 画面重定时 4.8 秒、2.4 秒李白单人参考图片尾。片头明确为「李白 · 两句生成实测」，片尾为「片段测试 · AI娱乐演绎」，全程保留 AI 生成标记。A02 同时标注时轴调整。

配音与节拍从锁定的 `work/music_final.wav` 截取 0–12 秒，再拼接原 21.6–24 秒尾奏，输出最后 0.8 秒淡出。原混音文件、人声参考音频和原视频字节均未修改。正文字幕保持原 heard 时间：A01 2.862–4.933 秒，A02 7.655–9.788 秒。

A02 沿用已记录的声学活动分组启发式画面变速，原片音轨筛查失败仍保留，不能称为精准口型通过。细节见 [A02-RETIME.md](A02-RETIME.md)。

输出为 1280×720、25 fps、360 帧、H.264/AAC、48 kHz 双声道，启用 faststart。25 fps 让 14.4 秒和 4.8 秒句槽精确落在完整帧边界；四句正式组装器仍维持 24 fps、24 秒。

重跑：

```powershell
node work/build-two-line-demo.mjs
```

此脚本只使用已有素材，不发起付费请求，不运行四片组装或发布。来源、控制点、原片与混音 SHA-256、编码参数和输出哈希保存在 `work/two-line-demo-report.json`。已完成整段解码、黑帧筛查、电平检查和九张抽帧复核；联系表为 `work/two-line-demo-review.jpg`，独立封面为 `final/libai-two-line-demo-preview.jpg`。这些检查证明文件可播放和包装正常，不证明逐词口型准确。
