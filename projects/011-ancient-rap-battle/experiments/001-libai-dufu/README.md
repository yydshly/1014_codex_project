# 实验 001 · 李白 vs 杜甫

先用四句原创歌词跑通“内容设定 → 原创参考 → 逐句人声 → 短镜头生成 → 音轨筛查与审片 → 按统一音乐剪辑”的最小闭环。执行日期：2026-10-15。

本实验已补齐**四句24秒完整基线**：李白A01、A02与杜甫B01、B02，三条网页标注H3和一条Seedance 2.0 Fast原片，1280×720、24fps、576帧。A01/B02原音轨筛查通过，A02/B01保留失败；A02画面沿用两组声学活动的分段重定时，不据此证明逐音素准确。B02约135分钟后取得下载文件，本次补齐不新增付费请求。直接API的HTTP402/code2068拒绝仍独立保留。详见[实验结果](RESULT.md)与[网页任务记录](docs/CHATART.md)。本次只生成实验目录中的独立完整文件，未替换主站public资源；原19.2秒三句视频、记录与网页留档保持原字节，没有公网部署。

## 与上游流程的对应

- 设计沿用：统一人设参考、单句人声驱动、镜头编号与时间表、素材候选、音轨筛查、人工审片和统一总音乐。四条真实原片与各自音轨筛查已齐，完整四镜头版本通过全解码与来源SHA核对。
- 替换：本轮以 ImageGen 生成原创人物图，以 MiniMax 节奏化 TTS 加本地合成的原创 100 BPM 节拍准备声音；没有使用 Midjourney 或 Suno。
- 简化：4 句而非 34 句，不运行围绕 16＋18 句编写的原版分镜脚本；使用独立的四镜头计划。
- 改进：每次远端创建前记录状态，收到 task ID 后立即保存；已提交的任务只查询，不在超时后自动重复创建。

## 制作范围与费用

四条各生成约5秒、取用或重定时为4.8秒，加2.4秒片头与2.4秒片尾，完整基线总计24秒，中间19.2秒全部来自四条真实生成视频。此前19.2秒三句版、24秒静态图预演和14.4秒李白两句版保留为独立过程产物，与完整四句版本区分。

实际网页任务为A01/B01/B02各一条MiniMax H3、每条75钻石，A02一条Seedance 2.0 Fast、60钻石；四条页面标价合计 **285钻石**，上限 **300钻石**，没有重抽。已观察到的前两条余额显示差额为135钻石，但四条最终扣减与账单未核对。直接API的10元参考预算不是ChatArt已支出。[价格与权限核查](docs/VIDEO-PREFLIGHT.md)

## 文件

- `episode.json`：本轮人物、歌词、镜头提示词、费用上限与时间槽。
- `refs/`：原创共同舞台图和两张单人参考，以及生成来源。
- `scripts/`：本轮音频、视频任务与剪辑脚本。
- `work/`：逐句声音、时间、任务、检查和选片记录。
- `clips/`：真实视频模型输出的候选镜头。
- `final/libai-dufu-sample-v1.mp4`：完整四句基线；24秒、1280×720、24fps、576帧、H.264/AAC。来源与剪辑参数见`work/assembly-report.json`，全解码和媒体/历史保全检查见`work/full-four-line-baseline-report.json`。
- `final/libai-dufu-three-line-demo-v1.mp4`：历史三句真实生成小样；19.2秒、1280×720、25fps、480帧，原视频及`work/three-line-demo-report.json`未改。
- `final/libai-dufu-rhythm-preview-v1.mp4`：历史静态图节奏预演，不是四句真实视频成片。
- `docs/`：接口核查与音频制作说明。
