# 《敬风霜》舞台版

本轮回应“场景单一、没有氛围和舞台感”的反馈：保留原歌与002的李白、杜甫表演，重新设计演出空间、镜头组织、灯光和现场气氛。它是002的舞台重剪，不是重新生成两位人物的开口视频。

[完整成片](final/jing-feng-shuang-stage-v3.mp4)已完成并接入本地网页主播放器：63.28秒、1280×720、25fps、1582帧，视频H.264、音频AAC／48kHz／双声道，文件25,573,442字节，SHA-256为`011c49f6527f84ca834ac319ad14bb97dd4a410b75a37729b00bf025382970d6`。实际参数与素材链见[完成报告](work/final-report.json)，[发布记录](work/publish-report.json)为`published-local`；尚未部署公网，浏览器实测统一记录在[项目验证记录](../../VERIFICATION.md)。

## 舞台与镜头

- 用圆形金纹地台、灯柱、三侧观众和湖面城市构成完整演出空间。
- 开场全景交代双方站位，再切双人对峙、观众反打和鼓阵特写。
- 人物演唱保留002两条真实视频，器乐与停拍段用新舞台图像运镜；两种画面来源分别记录。
- 灯束、薄雾和少量前景光点增加空间层次；灯光推进依据实际声音段落，静音段不使用插值拍点假装跟拍。
- 原曲约38.4–47.1秒存在长留白，约60.76秒后也接近静音；作为停拍、观众反应和结束气氛处理，不删除原歌内容。

## 素材与来源

新增4张场景由内置ImageGen生成：远景、双人、观众反打、鼓阵特写。同一远景还可派生另一种构图，不能算作第五次图像生成。每张图的完整提示词、参考图、默认输出位置和SHA见[图像生成记录](refs/generation-sources.json)。舞台清单见[stage-manifest.json](work/stage-manifest.json)。

音乐仍为用户提供《敬风霜》，用户说明由Gemini生成，具体模型未独立核验；原歌与四句歌词沿用002的确认记录。原片使用ChatArt网页标注的MiniMax H3两条视频，原片QA原样保留；本轮没有新增ChatArt视频请求或重抽，原两条视频的网页标价300钻属于002既有素材成本，不重复计为003新增视频支出。独立账单仍未核实，新图像和本地制作费用未单独核对。

李白、杜甫的相貌、现代麦克风与舞台演出均为AI娱乐创作，不是历史场景复原。图像运镜及灯光效果不等同于模型生成的连续人物表演，现有口型仍有误差。

## 本地复核与重做

需要Node.js 22或更新版本、FFmpeg／FFprobe、带Pillow和NumPy的Python；本地渲染不调用模型。可通过`FFMPEG_PATH`、`FFPROBE_PATH`与`PYTHON_PATH`指定已有工具。四张新图、音乐切点、批准清单及002源素材均须保留，发布器会核对实际SHA。

从仓库根目录进入本实验，只读检查现有成片及发布条件：

```powershell
cd projects/011-ancient-rap-battle/experiments/003-stage-edition
node scripts/publish-stage.mjs --check
```

如需重新生成预览或重做成片，可依次执行；`--render`会更新本实验输出和完成报告，不生成新付费素材。`assemble-stage.mjs --check`会将工作报告写成输入检查状态，不能当作现有完成记录的只读复核，现有成片应使用上面的发布器检查。

```powershell
node scripts/assemble-stage.mjs --preview
node scripts/assemble-stage.mjs --render
node scripts/publish-stage.mjs --check
```

只有重做后的完成报告与素材检查均通过，才更新本地网页主三件套，再构建网页：

```powershell
node scripts/publish-stage.mjs --publish
cd ../../web
npm run build
npm run check
```

发布器先验证002历史三件套未变，再替换主视频、封面及来源记录；网页构建和检查另核对001两版与002的全部历史SHA。它不修改002实验，不访问付费接口，不发布公网。日常观看和启动方式见[网页说明](../../web/README.md)。
